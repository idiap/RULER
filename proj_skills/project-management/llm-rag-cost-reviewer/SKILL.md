# LLM RAG Cost Reviewer

Use this skill to review cost reports generated by `llm-rag-cost-estimator`.

## Review Checklist

1. Confirm official pricing/model docs were refreshed for the current date.
2. Confirm the model, pricing tier, context band, and reasoning effort are named.
3. Confirm the estimate separates:
   - full-text recurring query cost;
   - explicit CoT-style rationale/output cost;
   - cached-input mitigation;
   - priority processing;
   - one-time or source-change-triggered extraction cost;
   - local neuro-symbolic query latency.
4. Confirm scalability plots cover query-count growth and reference-document growth.
5. Confirm source roots and token-estimation assumptions are visible.
6. Confirm latency is framed as an estimate, not a guaranteed SLA.
7. Confirm the narrative does not claim LLM+RAG is always worse; it should say the cost basis is unstable and recurring when full text is repeatedly interpreted.

## Red Flags

- Hidden pricing assumptions.
- No source date for model prices.
- Comparing one LLM query against an entire amortized neuro-symbolic pipeline without break-even analysis.
- Treating cached input as guaranteed for all future deployments.
- Treating explicit reasoning traces as free, hidden, or outside the billed output budget.
- Showing only one query volume or one corpus size when the user asked for scalability.
- Treating local CPU time as zero latency.
