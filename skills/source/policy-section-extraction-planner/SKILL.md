# Policy Section Extraction Planner

1. Start with the domain corpus manifest and its current reasoning requirements.
2. Identify exact section selectors and neighboring definitions or exceptions.
3. Prioritize sections needed by existing rules before optional background material.
4. Record the intended normative unit, evidence anchors, dependencies, and review gate.
5. Preserve parent context when extracting subclauses, tables, and cross-references.

The output is an extraction backlog with section priority, rationale, selector,
expected artifact, required context, and validation command. Extracted text remains
candidate evidence until grounding and domain review succeed.
