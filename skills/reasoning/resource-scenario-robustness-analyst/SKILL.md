# Resource Scenario Robustness Analyst

Run `uv run ruler portfolio stress`. Scenario content and probabilities are reviewed,
typed inputs; they are not model-generated. Preserve here-and-now decisions across
shared information sets, report expected cost and tail risk separately, and establish
decision-changing thresholds only through real digest-bound re-solves.

## Validation

`uv run ruler validate resource-portfolio`
